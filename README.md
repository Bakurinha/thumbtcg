# ThumbTCG

Editor de capas e thumbnails para partidas de Digimon TCG, com 10 layouts, imagens personalizadas e exportação em PNG. Base inicial para evolução do projeto e suporte futuro a outros TCGs.

## Como usar

1. Baixe o repositório e abra `index.html` em um navegador moderno.
2. Escolha um layout e selecione as imagens das cartas.
3. Personalize nomes, detalhes, cores, fontes e o texto central (VS, X ou outro texto).
4. Ajuste a visibilidade dos elementos da capa.
5. Clique em **Exportar PNG** para salvar a imagem em **1280 × 720**.

## Estrutura

- `index.html`: aplicação completa, com HTML, CSS e JavaScript no mesmo arquivo.
- `README.md`: apresentação e instruções.

Não exige instalação de dependências nem etapa de compilação. As imagens selecionadas são processadas no navegador.
